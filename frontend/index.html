How booking works

  1. Choose a room and time

    The booking page shows what is already reserved for the day you pick.

  2. Send your request

    The server checks the room for conflicts as soon as you submit the form.

  3. Get a confirmation or a decline

    If the slot is taken, the decline lists the times that are already booked so you can try another.
